This guide sets up a complete Ory development environment: an Ory account, the Ory CLI, a 
project on Ory Network, the Ory SDK, and a running Ory Tunnel. By the end, you'll have a 
working local setup for building your application's authentication and authorization on 
Ory Network. The five steps below are sequential — each assumes you've completed the previous 
one — so follow them in order.

## Create your Ory account at [Ory Console](https://console.ory.com/registration)

Go to [Ory Console](https://console.ory.com/registration) and follow the on-screen steps.

NOTE: As part of creating an account you will also create your first workspace and project.
